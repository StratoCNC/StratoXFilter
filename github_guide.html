Качване на проекта в GitHub

Стъпка по стъпка, с картинен интерфейс (без нито една команда в конзола). Дръж тази страница отворена и следвай точките една по една.

Първо — 5 думи на прост език

GitHub
сайт, който пази проекти онлайн и дава на другите да ги свалят.
Repository
„repo" = папката на един проект, качена в GitHub.
Commit
запаметена снимка на файловете ти в даден момент.
Publish / Push
изпращане на файловете нагоре към GitHub.
GitHub Desktop
безплатно приложение, което прави всичко това с бутони.

Ще ползваме GitHub Desktop — най-лесният път. Целият процес е ~20 минути веднъж.

1

Направи си безплатен GitHub акаунт

  • Отвори github.com/signup.
  • Въведи имейл → парола → username (това е публично име, избери прилично, напр. topurov или подобно).
  • Потвърди имейла (GitHub праща код на пощата ти).

Запиши си username-а и паролата — ще ти трябват след малко.

2

Провери какво НЯМА да се качва

Вече съм сложил в проекта файл .gitignore, който автоматично изключва:

  • папката с старите чатове (лично, не бива публично);
  • папката с официалните UCCNC/UC300 мануали (чужди авторски права — не се препубликуват);
  • служебния боклук (кеш, временни build файлове, тестови изходи, моите work-снимки).
Ти реши за тези

DESCRIPTION MANUAL.pdf (описанието на машината) и axes measurment.xlsx (суровите ти данни) — ако са твои и искаш да ги споделиш, остави ги; ако не — кажи ми и ще ги добавя към изключените. Официалните мануали НЕ ги качвай.

Нищо не изтриваш от диска — .gitignore само им казва „не отивайте в GitHub".

3

Инсталирай GitHub Desktop

  • Отвори desktop.github.com → Download for Windows.
  • Пусни свалилия се файл и изчакай да се инсталира (сам се отваря).
  • При първо стартиране → Sign in to GitHub.com → влез с акаунта от Стъпка 1 (браузърът ще те върне към приложението → Authorize).
  • Ако попита за име/имейл за commits — въведи каквото искаш (може същия username и имейл).
4

Направи проекта на repo

  • В GitHub Desktop: горе ляво File → Add local repository…
  • Натисни Choose… и посочи папката:
    C:\Users\topur\Desktop\StratoCNC X-Y FILTER
  • Ще каже, че тук още няма repo → кликни синия линк create a repository.
  • В прозореца: Name → напиши StratoXFilter (без интервали); Description (по избор). Полетата за Git ignore и License остави както са — вече ги имаш в папката. → Create repository.
Какво стана

Папката ти вече е „repo" на твоя компютър. Още НЕ е онлайн — това е следващата стъпка.

5

Направи първи commit (снимка на файловете)

  • Вляво виждаш списък с всички файлове, които ще влязат. Провери, че изключените ги НЯМА в списъка (папката със старите чатове и мануалите не бива да са там).
  • Долу ляво, в полето Summary, напиши напр. Initial commit.
  • Натисни синия бутон Commit to main.

Ако изключен файл все пак се появи в списъка — кажи ми, ще оправим .gitignore преди да качваш.

6

Публикувай онлайн

  • Горе се появява бутон Publish repository → натисни го.
  • В прозорчето: Name = StratoXFilter, Description по избор.
  • Махни отметката Keep this code private (за да е публично и хората да могат да го свалят).
  • → Publish repository.
Готово — вече е онлайн

Проектът ти живее на:
github.com/твоя-username/StratoXFilter
Това е линкът, който можеш да даваш на хората.

7

Направи „Release" за exe-то (препоръчано)

За да имат хората чист бутон Download за самото приложение:

  • Отвори страницата на repo-то в браузър (в GitHub Desktop: Repository → View on GitHub).
  • Вдясно кликни Releases → Create a new release (или Draft a new release).
  • Choose a tag → напиши v1.0 → Create new tag.
  • Release title: StratoXFilter v1.0. Кратко описание по избор.
  • Долу, в Attach binaries…, завлечи файла
    dist\StratoXFilter.exe — той се качва отделно.
  • → Publish release.

Сега на страницата на Release-а има директен линк за сваляне на exe-то — това слагаш като „download" линк във форум-поста.

8

Вземи си линковете за форум-поста

  • Проект / сорс: github.com/твоя-username/StratoXFilter
  • Сваляне (exe): линкът от Release-а (Стъпка 7).
  • Статия: публикуваната HTML статия — от нейната страница има меню за споделяне, което дава публичен линк.

Тези три ги слагаш на местата [DOWNLOAD_URL] и [ARTICLE_URL] в FORUM_POST.txt.

9

Как да обновяваш после (много лесно)

Всеки път, щом промениш нещо в папката:

  1. Отвори GitHub Desktop — то само показва какво се е променило.
  2. Напиши кратко Summary (напр. Fix typo in README).
  3. Commit to main → после горе Push origin.

Това е целият цикъл. Commit = запази, Push = качи.

Дребно, но полезно да го знаеш

Когато някой свали StratoXFilter.exe и го пусне, Windows може да покаже синьо предупреждение Windows protected your PC (защото exe-то не е с платен цифров подпис). Нормално е за всяко ново приложение — казва се на хората: кликни More info → Run anyway. Добре е да го споменеш във форум-поста.
